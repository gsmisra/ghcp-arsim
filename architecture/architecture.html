GHCP Supported Runtime Architecture

Only the Flask -> VS Code Bridge Extension -> VS Code LM API -> GHCP architecture is supported.

Notes

  • No PowerShell generation scripts are part of the supported architecture.
  • No VS Code UI automation or SendKeys workflow is supported.
  • The bridge extension communicates directly with VS Code language model APIs.
